# 面试复盘

该目录把已完成实验转换成可解释的面试知识，不单纯收集背诵题。

每个主题建议包含：

1. 一分钟结论；
2. 项目中的真实场景；
3. 关键数据结构或调用路径；
4. 自己遇到的故障和证据；
5. 常见追问；
6. 仍不确定的边界。

优先主题：

- Linux device/driver/bus 与 probe；
- Device Tree、clock、regulator、GPIO、pinctrl；
- V4L2、Media Controller、videobuf2；
- MIPI CSI-2、RAW10、RKISP、NV12；
- DMA-BUF、IOMMU、CMA；
- DRM/KMS Atomic 和 buffer 生命周期；
- perf/ftrace 与公平的性能对照实验。
